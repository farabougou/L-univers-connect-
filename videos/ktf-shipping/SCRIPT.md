# SCRIPT — KTF Shipping « Un trajet clair, dès le premier clic »

Voix : Orion (masculine) — à générer par le client, puis synchronisée sur les 6 séquences.
Texte : voix off proposée dans le brief (p. 6), découpée par séquence.

1. (0–7 s)   Un trajet clair commence par de bons repères. Sur le site de KTF Shipping, le design organise la découverte.
2. (7–16 s)  Des titres affirmés, des contrastes nets, une couleur qui guide le regard.
3. (16–27 s) Chaque service prend sa place dans une interface structurée.
4. (27–38 s) On explore les modes de transport, on consulte les départs, puis on accède à l'espace de suivi.
5. (38–50 s) La navigation relie les informations utiles et conduit vers la demande de devis. Du premier écran au dernier bouton, les mêmes repères visuels accompagnent la lecture.
6. (50–60 s) KTF Shipping : découvrez un univers de transport, pensé pour être parcouru. Rendez-vous sur ktf-shipping.com.
