# SCRIPT — SensExpress « Une signature qui se voit » (42 s, vertical)

Voix off proposée par le brief (p. 6) — à enregistrer (Orion, Aurora ou ElevenLabs), puis calée sur les séquences.
Lecture visée : 36 à 38 s, la musique accompagne la fermeture.

1. (0–5 s)   Une marque se reconnaît aussi à ce qu'elle fait ressentir.
2. (5–12 s)  Avec SensExpress, cet univers prend forme à l'écran. Le noir pose le décor. Le doré attire le regard.
3. (12–20 s) Les titres et les images invitent à découvrir les solutions olfactives. Hôtels, bureaux, maison et voiture : chaque espace ouvre sur une gamme à explorer.
4. (20–28 s) Le site présente les diffuseurs
5. (28–36 s) et vous guide vers un conseiller pour parler de votre projet.
6. (36–42 s) SensExpress. Éveillez vos sens. Découvrez cet univers sur sensexpress.com.
