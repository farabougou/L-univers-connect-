**Issue:** Writing paysage.html next to index.html fails check (multiple_root_compositions). Moving it to a subfolder with ../assets paths renders blank (the project server root is the subfolder). What worked: a subfolder project (paysage/index.html, meta.json, package.json) whose assets is a symlink to ../assets, generated by the same gen.py with a per-format layout table.

**Suggested improvement:** Document in studio-quality the two-format pattern: one generator, a FMT layout dict, second format as its own project folder with an assets link, both rendered in parallel. Note: a Windows checkout without symlink support gets a text file instead of the link.

**Principle:** One composition root per project; share assets by link, not by relative paths outside the project.
