**Issue:** The reel's end mark, an orange asterisk, was proposed for the user's avatar mask. The user noticed it looks like the Claude logo. It was replaced by a one-stroke M monogram.

**Suggested improvement:** Add a line to the acceptance grid: no symbol, mark or icon that could be read as an existing brand's logo, including the tools used to make the work.

**Principle:** Check any proposed mark against well-known logos before adoption; the marks the designer sees every day are the ones they no longer notice.
